# Exercícios Básicos de Java - Programação Orientada a Objetos

Este repositório contém uma coleção de exercícios básicos desenvolvidos para o aprendizado e prática da linguagem Java.

O material foi produzido durante a disciplina de POO do **Curso Técnico em Informática** oferecido pelo **IFTM (Instituto Federal de Educação, Ciência e Tecnologia do Triângulo Mineiro)**.

--

## 📚 Tópicos Abordados

Os exercícios estão organizados para cobrir progressivamente os seguintes tópicos:

* **Fundamentos do Java:**
    * Variáveis, tipos de dados e operadores
    * Estruturas de controle (condicionais `if/else`, `switch`)
    * Loops (repetição `for`, `while`, `do-while`)
    * Arrays (Vetores) e Matrizes

## 🛠️ Tecnologias Utilizadas

* **[Java](https://www.java.com/)** (Linguagem de programação principal)
* **(Opcional) IDE:** (Ex: [VS Code](https://code.visualstudio.com/), [Eclipse](https://www.eclipse.org/), [IntelliJ IDEA](https://www.jetbrains.com/idea/))

## 🚀 Como Executar

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
    ```

2.  **Navegue até a pasta do projeto:**
    ```bash
    cd seu-repositorio
    ```

3.  **Compile e execute os arquivos `.java`:**
    (Assumindo que você tenha o JDK - Java Development Kit - instalado)

    ```bash
    # Para compilar um arquivo
    javac NomeDoArquivo.java

    # Para executar o arquivo compilado
    java NomeDoArquivo
    ```
